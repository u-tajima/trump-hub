# TRUMP HUB

スマホからGitHub Pagesで遊べる、ローカルルール対応のオンライン・トランプゲーム集です。

## 収録ゲーム
- 大富豪（革命・8切り・階段・しばり・11バック・スペ3返し・禁止上がり・都落ち）
- 7ならべ（パス上限・A-Kトンネル・ジョーカー）
- スピード（2人リアルタイム対戦）
- ばば抜き / ジジ抜き
- ダウト
- 神経衰弱

## 遊び方
1. アプリを開いて「部屋をつくる」からゲームとローカルルールを選択
2. 表示された5文字の部屋コード（またはQRコード・招待リンク）を共有
3. 他の参加者は「部屋に入る」から部屋コードを入力して参加
